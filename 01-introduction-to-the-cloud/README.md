# Module 1 Quick Revision

## Cloud Computing

> On-demand delivery of IT resources over the internet with pay-as-you-go pricing.

## Client-Server Model

> Client sends a request → Server processes it → Server returns a response.

## Six Benefits of Cloud Computing

1. Trade fixed expense for variable expense.
2. Benefit from massive economies of scale.
3. Stop guessing capacity.
4. Increase speed and agility.
5. Stop spending money running and maintaining data centers.
6. Go global in minutes.

## AWS Global Infrastructure

```text
Region
 └── Multiple Availability Zones (AZs)
       └── One or more Data Centers
```

## Shared Responsibility Model

> AWS = Security **OF** the cloud.

> Customer = Security **IN** the cloud.

## Core Idea

AWS concepts work together to help businesses build solutions that can be scalable, globally deployed, resilient, and securely managed.
